# Example: Parameter optimisation sweep

```text
Use Trader Dev MCP to optimise this Pine Script strategy.

Rules:
- Establish the baseline first.
- Sweep only meaningful parameters.
- Do not optimise for net profit alone.
- Compare profit factor, max drawdown, average trade, number of trades, and stability.
- Test the best settings across multiple crypto pairs and nearby timeframes.
- Reject settings that only work on one symbol.
- Explain every setting change.

Parameters to test:
- Stop loss
- Take profit
- ATR multiplier
- Volatility filter length
- Regime filter threshold
- Cooldown bars
- Timeframe
- Symbol
```
