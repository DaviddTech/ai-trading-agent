# Example: Backtest a TradingView Pine Script strategy

Paste this into Claude Code, Codex, OpenClaw, or Cursor after installing Trader Dev MCP.

```text
I am going to paste a Pine Script from TradingView.

Your job:
1. Read the full script.
2. Tell me if it is an indicator or a strategy.
3. If it is an indicator, convert it into a clean `strategy()` only if the rules are clear.
4. Check for repainting, lookahead, and future-looking logic.
5. Prepare it for Trader Dev backtesting.
6. Backtest it on crypto pairs using Trader Dev.
7. Test more than one symbol and timeframe where possible.
8. Report net profit, profit factor, max drawdown, win rate, average trade, number of trades, and weaknesses.
9. Do not optimise yet. First establish the baseline.

Here is the Pine Script:

[PASTE SCRIPT HERE]
```
