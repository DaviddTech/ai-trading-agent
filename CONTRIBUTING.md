# Contributing

Thanks for helping improve AI Trader MCP.

Good contributions include:

- New prompts
- New skills
- Pine Script examples
- Backtest result templates
- Risk management workflows
- Optimizer workflows
- Docs and examples
- Screenshots and demo videos

## Prompt contribution format

Please include:

1. Prompt name
2. Intended agent
3. Trader Dev tools required
4. Market type
5. Risk warnings
6. Expected output format

## Strategy examples

If contributing Pine Script, please include:

- Script name
- Timeframe tested
- Symbols tested
- Backtest assumptions
- Known weaknesses
- No repainting confirmation

Do not submit reckless prompts that encourage unlimited martingale, hidden leverage, or live trading without testing.
