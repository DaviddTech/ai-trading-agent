# Growth Notes

This repo is designed around a simple open-source growth idea:

> Give any AI agent one message and turn it into a trading research desk.

## Viral hooks

- Build your own AI hedge fund
- Backtest TradingView Pine Scripts directly from Claude
- Let Codex optimise your strategy parameters
- Give OpenClaw a quant desk
- AI agents need their own TradingView
- Your agent can now test strategies instead of just writing code

## GitHub README principles

- Show the install command immediately.
- Give agents a single message to read.
- Make skills easy to find.
- Show real use cases.
- Ask for stars with a clear unlock.
- Make the repo useful even without reading all docs.

## Community flywheel

1. User stars repo.
2. User gives the skill to Claude or Codex.
3. Agent runs a backtest.
4. User shares screenshot.
5. More traders try it.
6. More prompts and skills are contributed.
7. More market support gets built.
